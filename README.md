# GameTheoryLab

**Advanced Micro Lab**: an interactive study app for the course *Advanced Microeconomics* (game theory, Prof. Carsten Helm, University of Oldenburg).

The app lives in [`app/`](app/). Open `app/index.html` in a browser; it runs offline and needs no build step.

What it contains:

- 18 lectures broken into small steps, with step-by-step derivations, interactive models and game trees
- every exercise-sheet question from WS 2023/24 to WS 2026/27 plus extra practice problems, solved step by step, with progress tracking and a random timed exercise test
- past exams with graded solutions, six mock exams, practice drills, derivation practice, a question bank, flashcards and a formula sheet
- a Game lab that solves any matrix game (best responses, IESDS, pure and mixed equilibria) and game trees
- an AI tutor that uses a free open-weight model by default (GPT-OSS 20B via Pollinations, no key needed)

See [`app/README.md`](app/README.md) for the file layout and how to add new material.

Course slides, exams, exercise sheets and literature are not included in this repository (copyright). Links to the slide PDFs in the app work when the app folder sits next to those files locally.
